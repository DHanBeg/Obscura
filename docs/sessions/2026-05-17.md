- `backend/internal/federation/federation.go` — Permissionless node kaydı. DB: `federation_nodes`. API: POST /v1/nodes/register, GET /v1/nodes, GET /v1/nodes/{id}, POST /v1/nodes/{id}/heartbeat. Heartbeat + 10dk inaktif prune.
